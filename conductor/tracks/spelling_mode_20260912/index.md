# Track: Spelling Practice Mode with Speech Synthesis

- **Track ID:** `spelling_mode_20260912`
- **Type:** Feature
- **Status:** New
- **Specification:** [spec.md](./spec.md)
- **Plan:** [plan.md](./plan.md)

## Summary
Expands FlashMath into spelling fluency with an untimed practice mode:
- Web Speech API synthesis for spoken word presentation and instant replay.
- Configurable word levels (starting with Grade 4 word collection).
- Immediate visual validation with answer reveal on incorrect submission.
- Level-specific stats (accuracy, best streak, attempts) saved in `localStorage`.
- Dedicated Mode Selector on the landing page for easy switching between Math Sprint and Spelling Practice.
